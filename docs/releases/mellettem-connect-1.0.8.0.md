# Mellettem Connect 1.0.8.0

- The Jellyfin settings page adapts to desktop and mobile widths and groups account details, connection history, and relay activity.
- New 16:9 artwork keeps the full Mellettem wordmark visible in Jellyfin’s catalog and installed plugin cards.

This public beta targets Jellyfin 12.3 and .NET 10. Existing installations retain their pairing. Install the update from the Mellettem Connect catalog and restart Jellyfin.
