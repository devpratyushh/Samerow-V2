# Mellettem identity

The original supplied artwork is `mellettem-original.png`. The web app's `public/mellettem-wordmark.png` is a crop of that artwork for headers and documentation; `public/mellettem.png` is the square symbol for browser icons. `public/mellettem-social.png` uses the original artwork for link previews. The Jellyfin plugin and catalog use the same 16:9 artwork at `jellyfin-plugin-mellettem/mellettem.png`.

Preserve the artwork's proportions, colors, and dark background. Use the full wordmark when space allows and the symbol at small sizes. The product name is **Mellettem**; the Jellyfin plugin is **Mellettem Connect**. Existing repository, service, protocol, and catalog identifiers remain stable for installed clients.
