# Security reporting

Please do not post credentials, connector tokens, private invitation links, or security exploits in public issues.

Use [GitHub private vulnerability reporting](https://github.com/devpratyushh/Samerow-V2/security/advisories/new) when available. If it is unavailable, open an issue requesting a private reporting channel without disclosing the vulnerability.

Include the affected version, reproduction steps, impact, and any proposed fix. Keep production credentials and personal media out of reports. Updates are distributed through this repository and the Mellettem Connect catalog; use the latest published version.
